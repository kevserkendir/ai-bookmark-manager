# Folder access

Labels:
- OPEN: read freely.
- LIMITED: open a file only when the human names it. Listing file names is fine
  only to find the named file. Never browse.
- CLOSED: ask the human before opening anything, every time.
- No label: stop and ask. Do not create unlabelled folders.

Folders:
- `starters/` - OPEN
- `handoff/` - OPEN
- `prompts/` - LIMITED
- `sandbox/` - LIMITED
- `prompts/OLD/` - CLOSED
